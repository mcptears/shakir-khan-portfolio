# Shakir Khan — Full Stack Developer

A modern, animated single-page portfolio website.

## ✨ Features

- Animated hero with typing effect and particle canvas
- Scroll-reveal animations throughout
- Animated skill bars and stat counters
- Project showcase cards with hover effects
- Experience timeline
- Contact section with form
- Fully responsive with mobile menu

## 🚀 View it live

Just open `index.html` in a browser, or serve it:

```bash
npx serve .
# or
python3 -m http.server 8000
```

## 🛠️ Built with

Plain HTML, CSS, and JavaScript — no build step, no dependencies.
Fonts loaded from Google Fonts (Space Grotesk + Inter).
